# ПЛК B&R в Automation Studio

[English version](README.en.md)

Лабораторная по программному обеспечению мехатронных и робототехнических систем (октябрь 2025): программа на C для контроллера B&R в среде Automation Studio, отлаженная в симуляторе ПЛК.

## Что делает программа

Циклическая задача (`Laba_1/Logical/Program/Cyclic.c`) моделирует два двигателя постоянного тока и сравнивает два способа управления:
- **первый двигатель** работает в разомкнутом контуре: напряжение задаётся пропорционально уставке скорости;
- **второй двигатель** работает под регулятором (`FB_Regulator`): на вход регулятора подаётся ошибка между уставкой и фактической скоростью.

Уставка меняется ступенькой: скорость 40 на 200-м цикле, сброс в 0 на 400-м. По графикам переменных в Automation Studio видно, как оба двигателя отрабатывают ступеньку.

`Init.c` и `Exit.c` отвечают за инициализацию и завершение программы, функциональные блоки двигателя и регулятора описаны в библиотеках проекта.

## Запуск

Откройте `Laba_1/LABA1.apj` в B&R Automation Studio и запустите конфигурацию в симуляторе (ARsim).
